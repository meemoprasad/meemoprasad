# Hi, I'm Meemo Prasad 👋

**Building Meeba Brain — evidence-backed code impact analysis for AI-generated changes.**

AI coding agents can write code quickly. But understanding what a change affects across a codebase is just as important.

I'm building Meeba Brain to help developers understand code changes with **file-and-line evidence**, trace potential impact across related code, and distinguish verified findings from what still needs investigation.

### 🚀 What I'm building

**Meeba Brain**
- 🔎 Evidence-backed debugging and code impact analysis
- 📍 Source references with exact file and line numbers
- 🧩 Code intelligence through a knowledge graph and MCP integrations
- 🛠️ Designed to complement AI coding tools and developer workflows
